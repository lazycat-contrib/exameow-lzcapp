# exameow - 懒猫云应用

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![LazyCat Cloud](https://img.shields.io/badge/LazyCat-Cloud-blue)](https://lazycat.cloud)

AI-powered exam question generator. Upload study materials, get exam questions in seconds.

## 功能特性

- 🤖 **AI 驱动**: 基于 LLM 的智能出题
- 📝 **多种题型**: 支持选择题、填空题、简答题等
- 📤 **材料上传**: 上传学习材料自动生成试题
- 🔒 **本地优先**: 数据存储在你的设备上
- 🌐 **跨平台**: 支持多种平台使用

## 安装说明

通过懒猫应用商店安装，搜索 "exameow" 即可。

## 配置参数

安装时需要配置以下参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| AI 接口地址 | OpenAI 兼容 API 地址 | https://api.openai.com/v1 |
| AI API 密钥 | LLM 服务 API 密钥 | 必填 |
| AI 模型 | 模型名称 | gpt-4o |
